# Tabi · הטיול שלנו ליפן

אפליקציית ווב (PWA) לתכנון ולניהול טיול של כ-30 יום ביפן. היא מותאמת לטלפון, ואפשר להתקין אותה למסך הבית.

- **היום**: ברכה אישית, מזג אוויר חי ביעד, ספירה לאחור לטיסה, "הדבר הבא" וציר הזמן של היום.
- **מפה**:
  - מפה חיה עם המיקום שלכם ("הנקודה הכחולה") וחיפוש מקומות.
  - המלצות לפי האזור שרואים במסך, לפי קטגוריות.
  - הוספה ועריכה של מקומות משלכם.
- **ניווט**: הכפתור "קח אותי לשם" פותח את Google Maps בטלפון עם היעד מוכן.
- **הטיול**: כל הימים במבט אחד, עם גרירה ושחרור בתוך יום ובין ימים.
- **חשבונות**:
  - התחברות והרשמה עם שם משתמש וסיסמה, בלי קודי אימות.
  - טיול משותף עם קוד הזמנה.

## הרצה במחשב

```bash
npm install
npm run dev
```

## חיבורים (אופציונלי)

בלי שום הגדרה האפליקציה עובדת במצב מקומי: החשבונות והנתונים נשמרים בדפדפן, והמפה חינמית (OpenStreetMap).
חשבונות משותפים בענן (Firebase, חינם) ומפת Google מוגדרים לפי המדריך: [docs/SETUP.md](docs/SETUP.md).

## טכנולוגיה

React 19 · TypeScript · Vite · Tailwind CSS 4 · Motion (Framer Motion) · Zustand · dnd-kit · Google Maps (`@vis.gl/react-google-maps`) / MapLibre · Firebase Auth + Firestore · vite-plugin-pwa.
